# Customer Resolution Agent

## Overview

Customer-facing airline disruption resolution agent built using Python and Streamlit.

This project demonstrates:

- Intent detection
- Policy evaluation
- Escalation handling
- Customer support automation
- Audit logging

## Features

### Intent Detection

- Refund Requests
- Rebooking Requests
- Compensation Requests
- Escalation Requests

### Sentiment Handling

Recognizes frustrated customers and responds professionally.

### Policy Engine

Applies airline disruption policies.

### Escalation Workflow

Generates escalation tickets when approval authority is exceeded.

### Audit Logging

Maintains complete conversation and action history.

## Technology Stack

- Python
- Streamlit
- JSON
- GitHub

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
